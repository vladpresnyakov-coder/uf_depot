# UF Depot

Инженерная платформа по ультрафильтрации: узел непосредственной коагуляции перед УФ и модуль UF Calc (промышленная УФ-система N+X).

## Версия 0.1 — что работает

| Раздел | Что делает |
| --- | --- |
| `/coagulation` | 5 коагулянтов, паспорт с обязательной базой концентрации, заданная доза, пересчёт баз (металл / Al₂O₃ / соль / кристаллогидрат / товарный), расходы при Qmin/Qном/Qmax, два режима расхода («только коагуляция» и «с установками УФ»), теоретический баланс щёлочности, коррекция pH (ручная доза или титрационная кривая), FeSO₄ с независимым статусом окисления, контактные камеры, трубопровод, требуемые характеристики насосов-дозаторов, протокол расчёта |
| `/uf` | Событийное годовое моделирование N установок: фильтрация → FF → BW, CEB по общему циклу, группы BW-станций, очередь и продление, баланс ОО с возвратом; режимы «найти Qnet» и «найти J» (обратный решатель с повторной проверкой) |
| `/methods` | Реестр методик: опубликована только ручная доза; методики, требующие источников |
| `/api/health` | Проверка состояния |
| `POST /api/coagulation/calculate`, `POST /api/uf/calculate` | Расчётные API (детерминированное ядро, без LLM) |

Не входит в v0.1: вход (e-mail, Telegram), сохранение проектов и версий, документы (ТКП, схема, DOCX/PDF/Excel), EN/ZH, редактор стадий и методик. Значения по умолчанию — демонстрационные.

## Структура

```
src/core/units         единицы и стехиометрия
src/core/coagulation   профили коагулянтов, пересчёты, расчёт, методики, безопасный парсер выражений
src/core/uf            балансы, шаблоны режимов, событийное ядро, обратный решатель
src/app                страницы и API (Next.js App Router)
tests                  Vitest: §24.1 A–D и функциональные проверки
docs                   описание проекта, исходные ТЗ, HTML-прототипы
```

## Запуск

```bash
npm install
npm test          # тесты ядра
npm run dev       # http://localhost:3000
npm run build && npm start
```

## Развёртывание

Railway, сервис из этого репозитория (`railway.json`): сборка `npm run test && npm run build`, старт `npm start` (порт из `PORT`), проверка `/api/health`. Секреты в v0.1 не нужны; будущие переменные — в `.env.example`.
