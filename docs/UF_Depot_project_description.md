## 1. Продуктовая цель

Публичный инженерный сервис для проектировщиков и пользователей ультрафильтрации. Не одностраничный калькулятор, а модульная платформа: личный кабинет, проекты, воспроизводимые версии расчётов, технические отчёты, возможность добавлять инструменты.

Инструменты:
1. **Узел непосредственной коагуляции перед УФ** — первый инструмент.
2. **UF Calc** — расчёт промышленной УФ-системы N+X (производительность, режимы, промывки, насосы, реагенты, документы).
3. Будущее: эксплуатационный журнал, массовая нагрузка ВВ, другие инструменты.

Структура данных:
`Пользователь → Проект → Источник / анализ воды → Технологическая линия → Узел коагуляции (необязательно) → УФ-система N+X → Версии расчётов → Документы`

Несколько источников и линий в проекте. Внутри одной УФ-системы все установки одинаковы.

## 2. Общие принципы (для обоих модулей)

1. **Разделение слоёв:** материальные балансы и пересчёты; предварительные оценки; химический баланс; подбор параметров оборудования; будущая эксплуатационная диагностика.
2. **Без вымышленных коэффициентов.** Нет методики — ручной ввод работает, автоматическая оценка сообщает «недостаточно данных».
3. **Предварительная оценка ≠ оптимум.** Слово «оптимальная доза» не используется.
4. **Требование ≠ результат.** SDI15, остаточный металл, ПО ультрафильтрата — заданные требования со статусом «Требование задано. Достижение расчётом не подтверждено; требуется проверка».
5. **Отсутствие данных ≠ ноль.**
6. **Неизменяемые снимки.** Версия расчёта хранит входы, паспорта, методики, коэффициенты, допущения, результаты, предупреждения. Изменение справочника не меняет старые версии; старые отчёты не пересчитываются автоматически.
7. **Детерминированное ядро без LLM.** Генеративная модель не выполняет расчёты и не нужна для стандартного отчёта.
8. **Происхождение каждого значения:** задано пользователем / шаблон задания / рекомендация изготовителя / демо / рассчитано / предложение.
9. **Раздельные статусы:** задано пользователем; предварительная оценка; требуется уточнение; расчёт не завершён; недостаточно данных. Один зелёный статус «всё рассчитано» при неполных данных недопустим.
10. **Демо-данные всегда помечены.**

## 4. Модуль 1 — Узел непосредственной коагуляции перед УФ

### 4.1. Технологическая последовательность

`Исходная вода → предфильтр F-100 → насос подачи P-100 → расходомер FT-101 → коррекция pH (при необходимости) → ввод коагулянта → смешение MX-101 → контактная камера CT-101 (резерв CT-102) → ультрафильтрация`

Предфильтр и насос исходной воды стоят **до ввода реагентов**, чтобы насос не разрушал хлопья, а предфильтр не забивался коагулянтом.

### 4.2. Границы первой версии

| Входит | Не входит (точка расширения) |
| --- | --- |
| 5 коагулянтов: ПОХА/PACl, FeCl₃, Fe₂(SO₄)₃, Al₂(SO₄)₃, FeSO₄ | Осветлители, флотация, отделение осадка до УФ |
| Паспорт продукта с обязательной базой концентрации | Подбор флокулянтов |
| Режимы «Заданная доза» и «Предварительная оценка» (только при методике) | Эксплуатационный журнал |
| Пересчёты: металл / оксид / соль / кристаллогидрат / товарный / рабочий раствор | Автооптимизация, АСУ ТП, управление оборудованием |
| Кислота/щёлочь (HCl, H₂SO₄, NaOH): ручная доза или титрационная зависимость | Полный гидравлический расчёт трубопроводов |
| Теоретический расход щёлочности — отдельно от дозы на целевой pH | Прогноз SDI15, остаточного металла, ПО |
| Контактные камеры 1 раб. + 1 рез., время ↔ объём | Каталоги насосов и труб |
| Диаметр трубы и скорости при Qmin / Qnom / Qmax | Утверждённая рабочая документация |
| Требуемые характеристики насосов-дозаторов | |
| ТКП, принципиальная P&ID, записка, спецификация; импорт Excel/CSV; экспорт PDF/Excel | |

### 4.3. Расход исходной воды — два режима

1. **«Только коагуляция»** — Qном задаёт пользователь; Qmin и Qmax необязательны (пусто = Qном).
2. **«С установками УФ»** — пользователь задаёт число рабочих установок и подачу исходной воды на одну установку. По умолчанию **Qmin = 1 рабочая установка**, **Qном = все рабочие установки**; диапазон можно изменить вручную.

Насос-дозатор подбирается так, чтобы при работе одной установки (Qmin) впрыск оставался равномерным. Камеры и труба по умолчанию подбираются по Qmax. При одной установке нужно проверить смешение и скорость в трубопроводе.

Демо-пример: 3 установки × 40 м³/ч → насос коагулянта 11–91 л/ч, регулирование 1:8, скорость в трубе при одной установке ≈ 0,5 м/с.

### 4.4. Паспорт продукта

Название*, производитель, марка, партия; форма* (жидкий/твёрдый); химическая форма; безводная соль / кристаллогидрат (n·H₂O)*; концентрация* + база*; плотность* (для жидких); для ПОХА — основность + определение, свободная кислотность; Fe²⁺/Fe³⁺; рабочий раствор: способ приготовления, концентрация + база.

Допустимые базы: Al; Al₂O₃; Fe; безводная соль; конкретный кристаллогидрат; товарный продукт. **Концентрация без базы не принимается.** Степень окисления железа всегда показана: Fe₂(SO₄)₃ — железо(III), FeSO₄ — железо(II).

### 4.5. Формулы

```
D_product = D_metal / w_metal,product
M_product (кг/ч) = D_product (мг/л) × Q (м³/ч) / 1000
q_product (л/ч) = M_product / ρ (кг/л)
q_working (л/ч) = D_basis × Q / C_same_basis (г/л)      — числитель и знаменатель в одной базе

t (с) = 3600 × V_eff / Q;   V_eff = Q × t / 3600;   V_geom = V_eff / k   (k — только с основанием)

d (м) = √(4 × (Q/3600) / (π × v))

Кислота/щёлочь: M100 = D100 × Q / 1000; Mком = M100 / w; qком = Mком / ρ; qраб = D100 × Q / C100
```

Массовые доли металла (атомные массы IUPAC: Al 26,982; Fe 55,845; O 15,999; S 32,06; Cl 35,45; H 1,008):

| Форма | M, г/моль | w металла | Металл → форма |
| --- | --- | --- | --- |
| Al₂O₃ | 101,96 | 0,5293 | 1,889 |
| Al₂(SO₄)₃ безводный | 342,15 | 0,1577 | 6,340 |
| Al₂(SO₄)₃·14H₂O | 594,36 | 0,0908 | 11,01 |
| Al₂(SO₄)₃·18H₂O | 666,43 | 0,0810 | 12,35 |
| FeCl₃ безводный | 162,20 | 0,3443 | 2,904 |
| FeCl₃·6H₂O | 270,29 | 0,2066 | 4,840 |
| Fe₂(SO₄)₃ безводный | 399,88 | 0,2793 | 3,580 |
| FeSO₄ безводный | 151,91 | 0,3676 | 2,720 |
| FeSO₄·7H₂O | 278,01 | 0,2009 | 4,978 |

Произвольный n кристаллогидрата считается ядром. Для ПОХА доля Al берётся только из паспорта.

Теоретический расход щёлочности (стехиометрия, **не прогноз pH**): Al³⁺ — 0,1112 мг-экв/мг Al; Fe³⁺ — 0,0537 мг-экв/мг Fe; ПОХА — 0,1112 × (1 − B); Fe²⁺ → Fe(OH)₃ — 0,0358 мг-экв/мг Fe и 0,143 мг O₂/мг Fe. Допущение — полный гидролиз до M(OH)₃.

### 4.6. Особая ветка FeSO₄

- Независимый статус проверки окисления: не проверено / требуется проверка / подтверждено методикой / подтверждено испытанием.
- Проверяется наличие O₂ или окислителя, pH, температуры, контактного времени.
- Стехиометрическая обеспеченность кислородом **не** считается подтверждением завершения окисления за контактное время.
- FeSO₄ не эквивалентен FeCl₃ по содержанию Fe. Фиктивная кинетика не создаётся. Безусловная рекомендация применения не выдаётся.

### 4.7. Насосы-дозаторы

Выход: qmin = q(Dmin, Qmin), qnom, qmax = q(Dmax, Qmax), требуемое давление (точка ввода + заданные потери), рекомендуемый диапазон (с явным запасом), кратность регулирования, требования к исполнению. Это требуемые характеристики, а не выбор модели. Резервирование — параметр (предложение 1 раб. + 1 рез.).

### 4.8. Карта экранов (19)

1. Главная · 2. Вход/регистрация · 3. Мои проекты · 4. Создание/редактирование проекта (требования к качеству) · 5. Структура проекта · 6. Мастер расчёта · 7. Исходная вода и импорт · 8. Коагулянт и паспорт · 9. Режим дозирования · 10. Коррекция pH · 11. Смешение и камеры · 12. Труба и насосы · 13. Результаты · 14. Сравнение вариантов · 15. Визуализация для ТКП · 16. P&ID · 17. Записка и спецификация · 18. Экспорт · 19. Эксплуатационный журнал (концепция).

Каждое поле: значение + единица + пересчёт во внутреннюю единицу; бейдж «нужно для: …»; базовые / дополнительные / условные блоки.

### 4.9. P&ID и записка

- P&ID строится из общей модели оборудования. Статусы позиций: рассчитано / условно показано / требует уточнения. Штамп «Принципиальная схема. Не является рабочей документацией».
- Позиции (предложение): F-100, P-100, FT-101, T-101/102, P-101A/B, P-102A/B, MX-101, AT-101, CT-101/102, XV-101…104, L-101, SP-1…3.
- Нотация: по мотивам ISO 10628 / ISO 14617, приборы по ISA 5.1 (альтернатива — ГОСТ 21.208 / 21.401).
- Записка (12 разделов): назначение, исходные данные, схема, методика, дозы и расходы, коррекция pH, трубопровод, насосы, камеры, ограничения, требуемые проверки, спецификация. Позиции и значения те же, что на P&ID.

### 4.10. Будущий эксплуатационный журнал (концепция)

Точки: исходная вода; перед УФ (лабораторно отфильтрованная проба: синяя/белая лента, производитель фильтра, метод подготовки, метод определения металла); ультрафильтрат. Запись: время и точка отбора, набор проб, фактические дозы, расход, партия реагента, комментарий. Размер пор по цвету ленты не назначается; металл не называется «растворённым» без согласованной методики.

## 5. Механизм расчётных методик (коагуляция)

### 5.1. Шесть независимых этапов ядра

1. Выбор дозы → 2. Конверсия базы → 3. Товарный и рабочий растворы → 4. Теоретический кислотно-основной баланс → 5. Определение коррекции pH → 6. Расходы и оборудование.

### 5.2. Профили коагулянтов

| Профиль | Металл | Базы | Щёлочность | Особые проверки |
| --- | --- | --- | --- | --- |
| PACl | Al(III) | Al, Al₂O₃, товарный | 3 мг-экв/ммоль × (1 − B) | основность и её определение |
| Al₂(SO₄)₃ | Al(III) | Al, Al₂O₃, соль, гидрат, товарный | 3 мг-экв/ммоль | безводная / гидрат (n) |
| FeCl₃ | Fe(III) | Fe, соль, гидрат, товарный | 3 мг-экв/ммоль | доля Fe²⁺ |
| Fe₂(SO₄)₃ | Fe(III) | Fe, соль, гидрат, товарный | 3 мг-экв/ммоль | доля Fe²⁺ |
| FeSO₄ | Fe(II) | Fe, соль, гидрат, товарный | 2 мг-экв/ммоль (при окислении O₂) | независимый статус окисления |

### 5.3. Запись методики (версионируемая, неизменяемая)

`id, version, coagulantType, productScope, modelType (manual | parameterizedExpression | lookupTable), inputVariables, outputBasis, coefficients (значение, единица, основание), applicabilityLimits, rangeRule, source, validationStatus, testCases, author, createdAt`

- Для выражения и таблицы обязательны единицы, область применимости и основание.
- Общий реестр v1: ручная доза для 5 профилей + шаблоны без коэффициентов. Методик предварительной оценки нет до получения источников.
- Пользователь создаёт персональную копию, меняет параметры, применяет к своим проектам. Общие методики не изменяются пользователями.
- Любая правка — новая версия. Если контрольные примеры не проходят, версия получает статус «личная, не верифицирована»; ожидаемые значения автоматически не меняются.
- Выражения разбираются собственным детерминированным парсером (без `eval`).

### 5.4. Дозы в интерфейсе — отдельно

- предварительный диапазон;
- центральная оценка (только если методика её задаёт; у таблиц не берётся как середина);
- доза, принятая пользователем;
- доза для максимальной подачи насоса — по умолчанию max(верх диапазона; принятая); вручную — с основанием, не ниже принятой.

### 5.5. Экраны механизма

Выбор методики · Редактор · Изменение коэффициента · Сравнение до/после · История версий · Пошаговый протокол расчёта · Методики, требующие подтверждения.

Демо-пример: коэффициент цветности b 0,05 → 0,04: центральная оценка 2,85 → 2,5 мг/л Al; диапазон 2,0–3,7 → 1,75–3,25; насос 15–84 → 13–74 л/ч; принятая доза и расход товарного продукта не меняются.

### 6.2. Обозначения и определения

- a — площадь модуля, м²; m — модулей в установке; A_unit = m × a; N — рабочих, X — резервных; A_work = N × A_unit; A_installed = (N + X) × A_unit; J — л/(м²·ч); T — часы периода.
- Тупиковая фильтрация: q_feed = q_permeate = J × A_unit / 1000 (только для фильтрации).
- **Q1** — исходная вода при фильтрации (на установку и на N).
- **Q2** — средний общий забор исходной воды за период (отдельно — только фильтрация).
- **Qnet** — (V_UF,произв − V_SN,UF) / T — нетто именно УФ, не продукта ОО.

### 6.3. Три режима

A. Найти Qnet (заданы площадь, J, режимы) · B. Найти площадь (заданы Qnet, J, режимы) · C. Найти J (заданы Qnet, площадь, режимы). Метки «Задано / Рассчитывается / Изменено пользователем». Если заданы все три — проверка согласованности и вопрос, какую считать зависимой.

### 6.4. Сквозной сценарий

1. J вручную (рекомендателя без источника нет) + требуемый Qnet (м³/ч или м³/сут).
2. Шаблонные стадии, общий цикл.
3. Предварительная площадь по нормативному циклу **без** ограничений общей станции (с пометкой).
4. Модуль, m, N, X, группы BW; сервис предлагает N, но сам не меняет.
5. Годовое моделирование с очередями → необходимый J при фиксированном Qnet: J исходный, J необходимый, Δ (абс. и %), невязка.
6. Переключатель «Сохранить исходный J и пересчитать Qnet».
7. Станции (Q/H), дозаторы CEB, реагенты, баланс ОО, связанный расход коагуляции.
8. Версия; ТКП и схема; после регистрации — DOCX и экспорт.

### 6.5. Стадии и режимная карта

- Стадия: ID, тип, название, порядок, время (с) и происхождение, расход q0 → q1 (л/(м²·ч) или м³/ч), источник, приёмник, производство УФ, отбор собственных нужд, дозирование, группа обслуживания.
- Объём: `V = (q0 + q1)/2 × t/3600`; частичный участок интегрируется точно (первая половина времени разгона = ¼ объёма).
- Общее время — вычисляемое, не отдельное поле.
- **Обычный цикл C:** фильтрация → FF исходной водой 30 с (расход = фильтрации, по умолчанию) → BW ультрафильтратом: разгон 7 + BWDB 30 + переключение 8 + BWDT 22 + останов 7 с (пример задания; Net BW = 60 с). Внутри FF УФ не производится.
- **CEB:** 1.1(A) щелочная; 1.1(B) щелочно-окислительная; 1 — щелочная + кислотная без промежуточной фильтрации (межстадийная отмывка — явная стадия); 2 — кислотная; 3 — окислительная; пользовательские. Одна химическая стадия: подача в нижний сброс → переход → подача в верхний сброс → останов → выдержка → отмывка нижний → переход → отмывка верхний. Шаблонные потоки: подача 120, отмывка 230 л/(м²·ч) (рекомендации S2 по заданию). Предварительная BW перед CEB не добавляется.
- **Общий цикл:** таблица «число полных обычных циклов → программа CEB», например `15 × C → CEB 1.1 → 10 × C → CEB 3 → повтор` (25 циклов и 2 CEB за повтор). Нет независимых календарей CEB.

### 6.6. Группы BW, очередь, продление

- В группе одна станция BW; одновременно одна установка выполняет BW или CEB; блокировка на всю CEB-программу, включая выдержку.
- Остальные фильтруют или ждут. Максимум продления фильтрации (0 — выключено).
- Алгоритм: заявка в конце фильтрации → обслуживание, если станция свободна → иначе продление на том же J → при пределе — явный останов (выработка на снижении учитывается), ожидание без выработки → пуск подачи и оставшаяся последовательность.
- Продление — часть того же фильтроцикла; счётчики не сбрасываются; J не повышается.

### 6.7. Источники CEB и баланс ОО

- Источник CEB (УФ / ОО-1 / ОО-2) — на подачу и все отмывки программы; обычная BW — на УФ.
- η1 = 0,75, η2 = 0,90; концентрат ОО-2 полностью возвращается на вход ОО-1; концентрат ОО-1 — в сброс.

```
k_UF = 1;  k_P1 = 1/η1 = 1,3333333333;  k_P2 = 1/(η1·η2) − (1 − η2)/η2 = 1,3703703704
F2 = V2/η2;  R2 = F2 − V2;  P1 = V1 + F2;  F1 = P1/η1;  UF_for_RO = F1 − R2;  C1 = F1 − P1
Проверка: UF_for_RO = V1 + V2 + C1
V_SN_UF = V_UF_direct + k_P1·V1 + k_P2·V2
Qnet = (V_UF_produced − V_SN_UF) / T
```

### 6.8. Насосные станции

- Выходы — Q и H. Марки, двигатели, КПД не подбираются.
- Станция исходной воды: мгновенный расход = сумма действующих ветвей (фильтрация, FF); диапазон по расписанию, максимум, сценарий одновременной фильтрации N. Не умножать на N + X; не брать Qnet или Q2.
- BW-станция: на группу; определяющий режим среди BW, CEB, отмывок; напор по каждому источнику.
- Напор: «задать» (значение + основание) или «рассчитать»:
  `H = (p_out − p_in)/(ρg) + (z_out − z_in) + h_потерь + ΔP_мембр/(ρg)`
- TMP фильтрации 1,5 бар, BW 3,0 бар — уставки заказчика (редактируемые), составляющая напора, не весь напор; не прибавлять повторно. Для FF — потери пути FF, не TMP.
- Неполные данные → выдаётся Q и неполный H с перечнем недостающих полей.

### 6.9. Реагенты CEB и метабисульфит

- Паспорт: название, формула/форма, производитель, база концентрации, массовая доля или г/л, плотность, рабочий раствор, источник/дата/версия. Массовая доля и массовая концентрация не взаимозаменяемы без плотности; NaOCl и активный хлор Cl₂ не смешиваются.
- Два способа: **заданная доза** (различать «добавить X мг/л» и «получить конечные X мг/л») и **целевой pH** (только по проверенной модели / титрованию). Нет методики → «Автоматическая доза по pH не определена», список недостающих данных, переход к заданной дозе без потери целевого pH.
- Формулы: `M_active = D·Q/1000`, `M_commercial = M_active/w`, `q_commercial = M_commercial/ρ`, `q_working = D·Q/C`; для события — интеграл D·Q по времени. На выдержке и отмывках дозирования нет.
- Выход: на один CEB, на общий цикл, сутки, среднесуточно за год, год; действующее и товарное (кг, л), рабочий раствор, максимальная подача л/ч. Удельный расход — отношение масс к нетто-объёму того же периода, кг/м³.
- Дозирующий комплект (кислота, щёлочь, гипохлорит) — на каждую группу BW.
- **Метабисульфит:** ручная доза на объём хлорсодержащих стоков; автоматический режим — только после методики с источником стехиометрии и запаса. Остаточный хлор не принимается равным концентрации CEB. Кислотные и хлорсодержащие стоки не смешиваются до подтверждённого обезвреживания. Максимальная подача без временного профиля не выдаётся.

### 6.10. Годовой расчёт

- Событийное ядро; аналитическое интегрирование линейных участков; без минутных шагов.
- Состояния установок, счётчики, строка общего цикла и очередь сохраняются между сутками.
- Частичные стадии на границах суток учитываются по всем потокам.
- Проектный год 365 × 24 ч (указывается явно).
- Выход: выбранные 24 ч; годовой объём; среднегодовой расход; среднесуточный; min/max и график суток. Год ≠ первые сутки × 365.
- Прогон до установившегося режима не входит в отчётный год.
- CIP, ремонты, тесты целостности, переходы на резерв исключены (обязательная оговорка).

### 6.11. Обратный решатель

- Один forward-алгоритм для всех режимов.
- Предварительная площадь — по удельной нетто-выработке полного повторяющегося цикла (если все расходы привязаны к площади); иначе — поиск с forward-проверкой. Удельная нетто-выработка ≤ 0 → площадь не выдаётся, объясняется причина.
- J при заданном Qnet — бисекция с проверкой знака на границах; нет смены знака → «недостижимо» и величина дефицита.
- Каждое решение подтверждается повторным forward-расчётом; хранятся J исходный и найденный, допуск, невязка, границы, итерации, статус.
- После округления числа модулей и принятия N — полный перерасчёт.

## 7. Визуализация для ТКП

Лист A4 альбомный, собственное решение (не копия примеров Inge System Design):
- плоский технологический разрез слева направо на отметке пола; три зоны: «Подача» (предфильтр и насос до ввода реагентов), «Узел коагуляции», «Узел ультрафильтрации»;
- трубы с цветом по потоку и легендой: исходная вода, коагулированная вода, фильтрат, коагулянт, pH-реагент, обратная промывка, реагенты CEB, сброс;
- позиции оборудования те же, что на P&ID;
- нижняя полоса: исходная вода и требования к фильтрату; ключевые цифры коагуляции; параметры УФ (пусто до расчёта УФ); легенда; штамп «Технологическая схема · лист 1 · расчёт · дата · статус»;
- все числа — из сохранённой версии; демо помечены; «Не является P&ID и рабочей документацией».

Без микросервисов, брокеров, векторных баз и генеративных агентов. Актуальные версии и API проверяются по официальной документации в момент реализации.

## 13. Критерии готовности первой рабочей версии

Пользователь может:
- зарегистрироваться (e-mail или Telegram), создать проект и линию;
- выбрать любой из пяти коагулянтов, однозначно задать концентрацию и базу дозы, выполнить расчёт по заданной дозе, получить предварительную оценку только при подходящей методике и увидеть причины невозможности расчёта;
- рассчитать расходы реагентов, параметры трубопровода, насосов-дозаторов и контактных камер;
- задать или принять J, найти площадь, принять компоновку N+X, получить новый J для требуемого Qnet либо Qnet при фиксированном J;
- отредактировать любую стадию, составить общий цикл, назначить группы и продление;
- получить суточный и годовой водный баланс, расходы реагентов и требования Q/H;
- сохранить неизменяемую версию, сравнить варианты;
- после регистрации выгрузить ТКП, схему, записку (PDF/DOCX), Excel и спецификацию на выбранном языке.

При этом:
- расчёты выполняются без LLM и покрыты тестами;
- неподтверждённые методики не подменяются правдоподобными числами;
- нет необоснованных обещаний качества воды и предварительных оценок под видом оптимума;
- ТКП, инженерное представление и экспорты используют один снимок и одинаковые числа.
