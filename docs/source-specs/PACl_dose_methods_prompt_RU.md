# Промпт для Claude: методика расчёта дозы ПОХА (полиоксихлорида алюминия)

## Задача

Ты — инженер-технолог водоподготовки и разработчик. Добавь в сервис «Расчётная доза коагулянта» методики для **полиоксихлорида алюминия (ПОХА, PAC, Al_n(OH)_mCl_(3n−m))**. Каждая методика — отдельная карточка: название по нормативному документу и типу коагулянта, ссылка на приложенный файл и пункт, входные параметры, формулы, единицы, ограничения и предупреждения.

Важное исходное условие: **ни один действующий нормативный документ РФ не содержит формулы дозы именно ПОХА по показателям исходной воды**. Поэтому:
- нормативный способ определения дозы ПОХА для питьевой воды — пробное коагулирование (ГОСТ Р 51642-2000, приложение А; СП 31.13330.2021, пп. 9.2, 9.15);
- расчётная (ориентировочная) формула есть только в отраслевом РД 153-34.1-37.502-2000 (п. 7.4). Она выражена в мг-экв/л и относится к коагулянтам вообще, а оксихлорид алюминия входит в перечень коагулянтов этого РД (п. 5.2.1, табл. 1; п. 5.2.4).
- формулу СНиП 2.04.02-84 п. 6.16 \(D = 4\sqrt{Ц}\) и табл. 16 **к ПОХА не применять**: в ней перечислены только Al₂(SO₄)₃, FeCl₃, Fe₂(SO₄)₃ по безводному веществу. Сервис должен блокировать выбор этой методики для ПОХА.

Не придумывай коэффициенты. Если расчёт — инженерная адаптация, а не прямое требование документа, помечай его статусом `adapted` и выводи предупреждение.

## Методика ПОХА-1: расчётная (ТЭС, предварительная оценка)

**Название:** «РД 153-34.1-37.502-2000, п. 7.4 — полиоксихлорид алюминия (ПОХА) по ГОСТ 34879-2022 — по перманганатной окисляемости».

Статус: `normative` для предочистки на ТЭС и в котельных; для ВОС — `reference`, только как предварительная оценка до пробного коагулирования.

Входные данные:
- ПО — перманганатная окисляемость исходной воды, мгO₂/л;
- Щ₀ — щёлочность исходной воды, мг-экв/л;
- C — массовая доля Al₂O₃ в товарном ПОХА, %, по паспорту продукта (ГОСТ 34879-2022, прил. Б);
- B — основность ПОХА, %, по паспорту (прил. Ж); можно выбрать марку НО/СО/ВО с подстановкой паспортного значения;
- ρ — плотность жидкого ПОХА, г/см³ (для твёрдого продукта не нужна);
- подщелачивающий реагент: известь (по CaO) или сода (по Na₂CO₃).

Расчёт:
1. Доза по эквиваленту алюминия (РД, п. 7.4; коэффициент сверен по лекционным материалам ТПУ, сверить с официальным текстом РД):
   \[ D_{экв} = 0{,}07 \cdot ПО, \text{ мг-экв/л} \]
2. Проверка по РД, п. 6.5: если \(D_{экв}\) < 0,3 или > 1,5 мг-экв/л — предупреждение «вне типового диапазона, обязательна пробная коагуляция».
3. Пересчёт на Al₂O₃ (1 мг-экв Al₂O₃ = 102/6 = 17 мг):
   \[ D_{Al_2O_3} = 17 \cdot D_{экв} \approx 1{,}19 \cdot ПО, \text{ мг/л} \]
   Это основная база дозы ПОХА, единая с ГОСТ Р 51642-2000. Дополнительно выводить \(D_{Al} = 0{,}5292 \cdot D_{Al_2O_3}\) (коэффициент из ГОСТ 34879-2022, прил. Ж).
4. Товарный продукт:
   \[ D_{тов} = D_{Al_2O_3} \cdot \frac{100}{C}, \text{ мг/л (= г/м³)}; \qquad V_{тов} = \frac{D_{тов}}{\rho}, \text{ мл/м³} \]
   Плюс расход в кг/ч и л/ч при заданной производительности Q, м³/ч.
5. Расход щёлочи (`adapted`). У ПОХА часть эквивалентов алюминия уже нейтрализована гидроксидом, поэтому щёлочность воды снижается на
   \[ \Delta Щ = D_{экв} \cdot \left(1 - \frac{B}{100}\right), \text{ мг-экв/л} \]
   Остаточная щёлочность: \(Щ_{ост} = Щ_0 - \Delta Щ\). Если \(Щ_{ост}\) < 0,5–1 мг-экв/л, предложить подщелачивание по формуле СНиП 2.04.02-84, п. 6.19 (СП 31.13330.2021, п. 9.16), где член \(Д_к/е_к\) заменён на \(\Delta Щ\):
   \[ Д_щ = К_щ (\Delta Щ - Щ_0) + 1, \text{ мг/л}; \quad К_щ = 28 \text{ (CaO)}, \; 53 \text{ (Na}_2\text{CO}_3) \]
   Если результат ≤ 0, подщелачивание не требуется. Обязательно вывести: «Замена \(Д_к/е_к\) на \(\Delta Щ\) — инженерная адаптация для ПОХА; в нормативе эквивалентные массы даны только для сульфата алюминия и солей железа».

Предупреждения в карточке:
- формула РД не учитывает pH, температуру, мутность и фракционный состав органики, поэтому оценка приблизительная;
- на практике высокоосновный ПОХА часто работает при меньших дозах Al₂O₃, чем сульфат алюминия, так что формула РД даёт консервативную оценку сверху; итоговая доза — по пробной коагуляции;
- для мутных вод (М > 50–100 мг/л) окисляемость не отражает нагрузку — требовать пробное коагулирование.

## Методика ПОХА-2: нормативная экспериментальная (ВОС, питьевая вода)

**Название:** «ГОСТ Р 51642-2000, приложение А; СП 31.13330.2021, пп. 9.2, 9.15 — полиоксихлорид алюминия (ПОХА) по ГОСТ 34879-2022 — оптимальная доза по пробному коагулированию».

Статус: `normative`. Это основная методика для проектной дозы ПОХА.

Функции модуля:
1. **Рабочий раствор** (ГОСТ Р 51642-2000, п. 5.4.2): навеска товарного ПОХА, содержащая 1,0 г Al₂O₃, на 1 дм³:
   \[ m = \frac{1{,}0 \cdot 100}{C}, \text{ г} \]
   Тогда 1 см³ рабочего раствора на 1 дм³ пробы = 1 мг/дм³ Al₂O₃.
2. **Протокол jar-теста** (прил. А): ввод серии доз 1, 2, 3…n мг/дм³ Al₂O₃. Режим: 140 об/мин — 3 мин, затем 40 об/мин — 15 мин, отстаивание 30 мин, фильтрование через бумажный фильтр. Температура испытаний — (4 ± 1) °C и (20 ± 1) °C или фактическая температура воды.
3. **Ввод результатов** по каждой дозе: мутность, цветность, ПО, остаточный алюминий, pH (и железо при необходимости).
4. **Выбор оптимальной дозы** (п. 3.7, А.5): наименьшая доза, при которой выполнены все нормативы питьевой воды. Нормативы держать в редактируемом справочнике (по умолчанию значения действующего СанПиН 1.2.3685-21; в табл. 1 ГОСТ Р 51642-2000 для модельных растворов указаны мутность 1,5 мг/дм³, цветность 20°, Al ≤ 0,5 мг/дм³, pH 6–9).
5. **Сезонность** (СП, п. 9.15): хранить оптимальные дозы по характерным периодам года (паводок, межень, ледостав), в проект брать максимальную расчётную дозу и диапазон регулирования дозаторов.
6. Пересчёт выбранной дозы в товарный продукт и расход — как в п. 4 методики ПОХА-1.
7. Если экспериментальных данных нет, показывать результат методики ПОХА-1 с плашкой «предварительная оценка, не является проектной дозой по ГОСТ Р 51642-2000».

## Справочный пересчёт с сульфата алюминия (опционально)

Статус: `reference`, без нормативного статуса. Если пользователь имеет дозу сульфата алюминия по безводному веществу \(D_{СА}\):
\[ D_{Al_2O_3}^{СА} = D_{СА} \cdot \frac{102}{342} \approx 0{,}298 \cdot D_{СА} \]
Перевод в ПОХА — через коэффициент эффективности \(k\), который задаёт пользователь по данным пробной коагуляции или производителя: \(D_{Al_2O_3}^{ПОХА} = k \cdot D_{Al_2O_3}^{СА}\). Значения по умолчанию не подставлять.

- Рекомендация методики по типу объекта: ТЭС/котельная → ПОХА-1 (normative) + ПОХА-2; ВОС → ПОХА-2 (normative), ПОХА-1 только как оценка.
- В отчёте указывать документ и пункт для каждой формулы и показывать цитату из приложенного файла.

## Контрольные примеры для тестов

Исходные данные: ПО = 10 мгO₂/л, Щ₀ = 1,2 мг-экв/л, ПОХА жидкий: C = 17 %, B = 70 %, ρ = 1,30 г/см³, Q = 100 м³/ч.

| Величина | Ожидаемое значение |
|---|---|
| \(D_{экв}\) | 0,70 мг-экв/л, в диапазоне 0,3–1,5 |
| \(D_{Al_2O_3}\) | 11,9 мг/л |
| \(D_{Al}\) | 6,30 мг/л |
| \(D_{тов}\) | 70,0 мг/л (г/м³) |
| \(V_{тов}\) | 53,8 мл/м³; 5,38 л/ч; 7,0 кг/ч |
| \(\Delta Щ\) | 0,21 мг-экв/л |
| \(Щ_{ост}\) | 0,99 мг-экв/л, подщелачивание: \(28 \cdot (0{,}21 - 1{,}2) + 1 < 0\), не требуется |
| Рабочий раствор | навеска 5,88 г товарного ПОХА на 1 дм³ |

Отдельный тест: при выборе методики «СНиП 2.04.02-84, п. 6.16» для коагулянта PAC сервис возвращает ошибку «методика не распространяется на ПОХА».
