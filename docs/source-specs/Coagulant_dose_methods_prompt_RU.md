# Промпт для Claude: методики расчёта дозы коагулянта в сервисе

## Роль и задача

Ты — инженер-технолог водоподготовки и разработчик. Нужно добавить в сервис модуль «Расчётная доза коагулянта по параметрам исходной воды». Каждая методика — отдельная сущность с названием «[Нормативный документ, пункт] — [тип коагулянта] — [определяющий параметр]», ссылкой на приложенный файл нормативного документа, входными параметрами, формулой, единицами, ограничениями и предупреждениями.

Не придумывай коэффициенты. Если формула в приложенном тексте отображается пустым местом (в исходном HTML формулы были картинками), используй формулу из этого промпта и пометь в карточке методики: «формула сверена по вторичному источнику, требуется сверка с официальным текстом».

## Методика 1

**Название:** «СНиП 2.04.02-84*, п. 6.16 — сульфат алюминия / хлорное железо / сульфат железа(III) (безводные) — по цветности и мутности».

- Область: хозяйственно-питьевые и производственные водопроводы, поверхностные воды.
- Коагулянты: Al₂(SO₄)₃, FeCl₃, Fe₂(SO₄)₃; доза в мг/л **по безводному веществу**.
- Входные данные: цветность Ц, град; мутность М, мг/л; тип сооружения (отстойник/осветлитель или контактный осветлитель/фильтр с контактной коагуляцией).
- Расчёт:
  1. По цветности, формула (6): \( D_ц = 4\sqrt{Ц} \), мг/л.
  2. По мутности, табл. 16 (диапазон, мг/л): до 100 → 25–35; 100–200 → 30–40; 200–400 → 35–45; 400–600 → 45–50; 600–800 → 50–60; 800–1000 → 60–70; 1000–1500 → 70–80. Меньшие значения — для грубодисперсной взвеси (дать пользователю выбор: нижняя/средняя/верхняя граница).
  3. Примечание к п. 6.16: при одновременной мутности и цветности принимается **большая** из доз.
  4. Примечание 2 к табл. 16: для контактных осветлителей/фильтров с коагуляцией в загрузке — уменьшить на 10–15 %.
- Пересчёты в выводе: на товарный продукт (через содержание основного вещества, ввод пользователем) и на Al₂O₃ (для сульфата алюминия × 102/342 ≈ 0,298).
- Ограничения: мутность > 1500 мг/л — вне таблицы, выдавать ошибку. СНиП заменён СП 31.13330 — выводить предупреждение «методика из отменённого документа, применяется как справочная / для предварительной оценки; проектная доза — по пробной коагуляции (СП 31.13330.2021, пп. 9.2, 9.15)».
- Связанный расчёт (опционально): взвесь, поступающая в отстойник, п. 6.65, формула (11): \( C_в = M + K_к D_к + 0{,}25Ц + В_н \), где \(K_к\) = 0,5 (очищенный сульфат алюминия), 1,2 (нефелиновый), 0,7 (хлорное железо).

## Методика 2

**Название:** «РД 153-34.1-37.502-2000, п. 7.4 — сульфат алюминия (по эквиваленту) — по перманганатной окисляемости».

- Область: предочистка исходной воды на ТЭС и котельных (поверхностные источники); основная методика для энергетики, т. к. СП 31.13330.2021 исключает водоподготовку теплоэнергетических объектов.
- Входные: перманганатная окисляемость ПО, мгO₂/л.
- Расчёт (ориентировочная формула при отсутствии экспериментальных данных): \( D_к = 0{,}07 \cdot ПО \), мг-экв/л.
- Пересчёты: в мг/л Al₂O₃: × 17 → \( D \approx 1{,}19 \cdot ПО \) (так у ЗХР); в мг/л безводного Al₂(SO₄)₃: × 57; для FeCl₃: × 54,1; для Fe₂(SO₄)₃: × 66,6 (применение к солям железа — показывать как пересчёт по эквиваленту, а не как прямое требование РД).
- Проверка (п. 6.5): результат сравнить с типовым диапазоном 0,3–1,5 мг-экв/л; вне диапазона — предупреждение.
- Предупреждения: формула не учитывает pH и щёлочность; доза принимается по пробной коагуляции или данным эксплуатации установок на той же воде; проверить щёлочность на достаточность для гидролиза (при нехватке — подщелачивание).

## Справочные (ненормативные) методики

Добавить с пометкой «справочно, без нормативного статуса»:

1. **Rodriguez et al., 2000 — сульфат алюминия (по Al₂O₃) — по TOC, щёлочности и pH:** \( D = 3{,}25 + 0{,}8\,TOC + 2{,}5\,[HCO_3^-] + 0{,}25\,pH \), мг/л Al₂O₃; TOC в мг/л, [HCO₃⁻] в мг-экв/л. Источник: J. Water Supply: Research and Technology – AQUA, 49:2, 57–73.
2. **ЗХР, эмпирическая — сульфат алюминия (по Al₂O₃) — по снижению ПО:** \( D_{Al_2O_3} = 0{,}9\,(ПО_{исх} - ПО_{кон}) \), мг/л; плюс оценка органического шлама ≈ 3,5 мг на 1 мг Al₂O₃.
3. В интерфейсе показать вывод статьи: для низкомутных цветных вод окисляемость точнее цветности; зависимость Ц ≈ ПО^γ (γ ≈ 1,3–2,4 по водоисточникам), а СНиП фактически предполагает γ = 2.

## Требования к реализации

- Модель данных: `Method {id, title, normative_doc, clause, file_ref, coagulant_types[], inputs[], formula, units_out, basis (anhydrous|Al2O3|mg-eq), limits, warnings[], status (normative|reference|superseded)}`.
- Выбор методики пользователем + «рекомендуемая» по типу объекта (ВОС → методика 1 со ссылкой на СП 31.13330.2021; ТЭС → методика 2).
- Вывод: доза в выбранной базе, все пересчёты, ссылка на документ/пункт с открытием цитаты из приложенного файла, список предупреждений.
- Юнит-тесты: Ц = 64 → 32 мг/л; М = 250, Ц = 25 → max(35–45; 20) = 35–45 мг/л; контактный осветлитель −10–15 %; ПО = 10 → 0,7 мг-экв/л ≈ 11,9 мг/л Al₂O₃ ≈ 39,9 мг/л Al₂(SO₄)₃.
- Не выдавать результат как окончательную проектную дозу: всегда выводить, что доза уточняется пробной коагуляцией и при наладке.
